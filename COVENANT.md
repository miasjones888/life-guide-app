# COVENANT

This file is Mia's list of what the app must **never** do.

It is the one document in this repo that Claude does not author. If a PR
violates anything on this list, it doesn't ship — no matter how clever the
feature.

When in doubt, re-read this. When a feature feels wrong but you can't
articulate why, it's probably listed here.
